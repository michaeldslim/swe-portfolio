# JavaScript Core Fundamentals for Technical Interviews

This repository contains comprehensive notes on JavaScript core concepts, perfect for technical interview preparation. The content is available in two formats:

1. **Markdown File**: `javascript-fundamentals.md` - Raw markdown content
2. **Web Interface**: `index.html` - Interactive web version with navigation

## How to Use

1. Open `index.html` in a web browser to view the interactive version
2. Or read `javascript-fundamentals.md` directly in any markdown viewer

## Topics Covered

- Execution Context & Hoisting
- Scope & Closures
- `this` Keyword
- Prototypes & Inheritance
- Asynchronous JavaScript
- ES6+ Features
- And more...
